Namespace

Everything lives in a single namespace: Invex.Process.

Public surface at a glance

Type Kind Description
IProcessRunner interface Injectable service for executing external processes. Exposes synchronous Run and asynchronous RunAsync. Registered as a singleton.
ProcessRunOptions record Immutable configuration for a single execution — executable name, arguments, working directory, environment variables, log levels, per-line transforms, and failure tolerance.
ProcessRunResult record The result of a completed execution — exit code, full captured stdout/stderr, and the originating options.
ProcessHostExtensions static class IServiceCollection extensions; call AddProcessRunner() once during host setup.

Typical flow

  1. Register the runner with AddProcessRunner().
  2. Inject IProcessRunner where you need to shell out.
  3. Build a ProcessRunOptions describing the invocation.
  4. Call Run or RunAsync and use the returned ProcessRunResult.
var result = await processRunner.RunAsync(
    new ProcessRunOptions("git", "rev-parse HEAD")
    {
        WorkingDirectory = repoRoot,
    },
    cancellationToken);

var commitSha = result.Output.Trim();
