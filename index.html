Invex.Process

A small, focused .NET library for running external processes with first-class logging, real-time output streaming, full output capture, and fail-fast error handling. It wraps System.Diagnostics.Process behind a clean, injectable IProcessRunner abstraction so your build targets, tools, and services can shell out to executables (dotnet, git, npm, …) without re-implementing redirection, buffering, and exit-code handling every time.
